# Roka Hula Food Flashcards

A static GitHub Pages study site built from the Roka Hula Food Training July 2026 guide.

## Upload to GitHub

1. Download and unzip the project.
2. Open your new GitHub repository.
3. Click **Add file > Upload files**.
4. Drag **everything inside this folder** into the repository. Do not upload only the ZIP.
5. Make sure these are at the repository root:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `cards.js`
   - `assets/` (contains the food photos)
6. Commit the files.
7. Go to **Settings > Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Choose branch `main` and folder `/ (root)`, then save.

## Important

The `assets` folder is required. If it is missing, the flashcards will still load but the photos will not.

The flashcards include 75 unique food items. Happy-hour/lunch duplicates are intentionally not separate cards. Images and menu components come from the supplied training guide. The "Easy customer comparison" text is a study aid, not official menu wording.
